Two WhatsApp MCP servers, two different jobs for your AI assistant

MCP (Model Context Protocol) is an open specification through which an AI assistant reaches external tools in a structured way, within the permissions it has been granted. For WhatsApp there are now two MCP servers, and comparing them as better or worse misses the point. They operate different layers.

Meta's server: setting up the platform

Meta's offering, called WhatsApp Business Tools MCP, is still in beta, runs remotely and authenticates through Meta OAuth. Its documented scope: finding business accounts, registering and verifying numbers, managing templates, sending messages (open text within the 24 hour customer window, otherwise templates) and setting up webhooks. Meta positions it for development and testing, not large scale production sending. Group and community tools are not listed.

The 9bot server: running groups day to day

The 9bot MCP server is aimed at the groups and communities of a company's own number, linked by pairing code or QR code. Its published toolsets cover groups, reports, workflows, messages, schedules, automations, moderation, integrations, community and jobs. New applications start with Groups, Reports and Workflows enabled.

Guardrails on the 9bot side

  • OAuth 2.1 with scopes, so each client holds only approved permissions.
  • Group level control: an application sees only the groups it was authorized for.
  • Allowlists and denylists of tools, plus read only applications.
  • A preview and a single use confirmation before sensitive actions.
  • Policies that block, mask or allow sensitive data.
  • A full audit trail of actions.

Practical examples

A developer uses Meta's server to create a test number, draft a template and validate a Cloud API webhook during an integration project. On the 9bot side, a community lead has Claude pull a weekly activity summary covering all customer groups, the marketing team asks ChatGPT to set up a workflow that posts a Friday reminder, and operations connect group commands to a CRM.

Nothing stops a company from using both: Meta's stack for individual customer conversations, 9bot for the group side.
