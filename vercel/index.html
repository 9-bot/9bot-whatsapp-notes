Eight seats per group: who the official WhatsApp Groups API really serves

When a company hears that Meta has an official Groups API, the first assumption is often that it can run customer communities, reseller networks or partner groups through code. The documentation, checked on November 6, 2026, describes something much narrower.

The core limits

  • Access is limited to Cloud API numbers holding Official Business Account (OBA) status.
  • A group holds at most 8 participants.
  • A number can run up to 10,000 such groups.
  • People join only through an invite link; the API cannot add anyone directly.
  • Pricing is per message, under Meta's rate card.

The OBA hurdle

Meta grants OBA status to verified businesses that, among other criteria, follow the Business Messaging Policy, have been on the platform for at least 30 days, have a verified business portfolio, use two-step verification and have an approved display name. Employee numbers, test accounts and Business app numbers are excluded, and a rejected request means waiting 30 days to reapply.

What API groups cannot do

Voice and video calls, disappearing or view once content, button and list messages, and the option to hide the participant list are all unsupported. The gap that matters most for operations: messages cannot be edited or deleted. So the API cannot remove a spam link or an insult, which rules it out as a moderation tool.

Where it fits

Small service conversations where a few people need the same thread: a customer with an account manager and a supervisor, a support case with vendor and technician, or onboarding a B2B client with the project team.

Where it does not

Communities of buyers, distributors or staff that run into the dozens or hundreds. Those still live in regular WhatsApp groups and communities. Tools like 9bot connect to the admin number as a linked device, by QR code or pairing code, and handle moderation, scheduling, welcomes and reports. That is not the Cloud API, and WhatsApp does not allow bulk or automated blasting, so automation should organize groups rather than spam them.

A three question test

More than 8 people per group? The API is out. No OBA or developers? Out as well. Need to delete messages? Out again.
